This project is far from being a finished product. It was mainly an opportunity to experiment with GPU programming and gain a better understanding of how particle systems work under the hood.

My goal was to see if I could build a particle system similar to those found in popular game engines, using C++ and OpenGL. I combined some of the knowledge I already had, such as 3D noise generation, procedural motion using forces, and compute shaders, to create a real-time simulation. I wanted to at least have some exposed parameters to see how with a simple generic particle system we could achieve some differnt results.
